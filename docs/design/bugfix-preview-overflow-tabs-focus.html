2 · Settings — initial focus on the close button

Settings

Site

Focus lands on the close button — the first focusable in DOM order and present on every tab — with a forced visible ring. Programmatic focus after a mouse click usually does not match :focus-visible, so the opening move adds stg-initial-focus until the first key or click. The app behind the backdrop is inert, so it reads as a still frame: no hover, caret, or focus ring.
