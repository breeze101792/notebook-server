Notebook server · Search side panel

Clear control for the search field

The × lives inside the field's right edge and appears only when the trimmed query is non-empty. Type in any field below. The field keeps the same width and padding whether the × is shown or hidden.

Clear-button states · desktop 22 px box, 12 px glyph

default · --fg-muted
hover · --accent-soft
pressed · accent border
focus-visible · 2 px ring
Placement — absolute inside the wrapper; right: 5 px desktop, 1 px phone; vertically centred.
Slot — input padding-right 32 px desktop / 48 px phone, always reserved. Never overlapped.
Phone — 44 × 44 button, 14 px glyph, 8 px radius. Matches --m-hit.
Visibility — hidden when value.trim() === ""; removed from tab order and a11y tree.
Focus order — input → × → Advanced toggle. Aa now lives inside Advanced. Focus returns to the input after clearing.
Native cancel — ::-webkit-search-cancel-button hidden; Firefox has none.

Design reference, not production. Tokens and component metrics are copied from static/css/style.css; the wrapper, clear button, and --search-clear-* tokens are the proposed addition. See docs/design/search-panel-clear.md for the normative spec, including keyboard, screen-reader, native-cancel, and debounce rules.
