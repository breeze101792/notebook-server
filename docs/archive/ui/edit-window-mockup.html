One edit window shell

All three hybrid editors share one chrome, one box and now one action bar: a single full-width row under the header that holds whatever the window can do, with the same Undo/Redo pair pinned at its right edge. The table’s tool row becomes that bar; the designers gain it. Edit bar is the default, Header history is the previous variant, Current is today’s shipped chrome.

Width drives all three windows at once, all three sharing the same 1320 × 768 box. 1280: the bar’s left slot fits the table’s 20 tools and its sort field on one line. 720: the left slot scrolls sideways, the history pair stays pinned and visible, the footer wraps its status onto its own row, and the designers go compact (Mermaid strip, DW + ▦ ⌨ nav). Layout swaps the chrome on the same bodies. The title ellipsises only when the header runs out of room — without the history pair the header’s fixed cost is 147 px, so at 720 it still has 573 px.

  1. 1
    One action bar, all three windows

    The same row directly under the header: full width, 57 px (6 + 44 + 6 + 1), --bg-elev, one 1 px seam below. The table’s old 48 px tool strip moves into this bar; the designers gain it.

  2. 2
    The left slot is the window’s own

    Table: Rows, Columns, Clipboard, Alignment, Sort, Table — 20 icon tools plus the sort field, in six groups with 1 × 20 px separators. Mermaid: Select Connect Add Chart. WaveDrom: Add Chart Source. Everything else stays where it was.

  3. 3
    History pair, right of a seam

    One 44 px Undo/Redo pair per window, #<prefix>-undo and #<prefix>-redo, behind a 1 × 24 px seam. Icon-only, aria-label and a tooltip naming the chord. States here: table both dead (clean open), Mermaid Undo live / Redo dead, WaveDrom both live.

  4. 4
    A reserved slot, not an action

    The dashed + at the far right is a placeholder for future per-window actions. It is not a button, not in the tab order, and the mockup invents nothing behind it. When a window gains a real action, a real control takes the slot.

  5. 5
    Footer is commit-only, unchanged

    Status, Cancel, Apply — same height, padding, gap and order in all three. No hint anywhere; Cancel carries aria-keyshortcuts="Escape". At 720 the status takes its own row so the actions stay 44 px on row two.

  6. 6
    Overflow, never a second row

    At 720 the table’s tools do not fit one line, so the left slot scrolls sideways behind a … affordance. The bar keeps its 57 px height and the history pair never scrolls away. A wrapped tool row would push the grid down by 40 px; a scroll costs nothing.

  7. 7
    What stayed put

    Both sidebars keep the add form, the chart controls and the inspector, and neither has a History section. WaveDrom’s compact strip is still + ▦ ⌨. The table body is a flush grid under the bar, with no tool strip of its own.
