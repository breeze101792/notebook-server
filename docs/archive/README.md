# Archive — frozen design records

Old design handoffs and mockups, kept for history. Nothing here is maintained, and
nothing here is a current spec. When a surface is redesigned, its new spec goes in
[`../ui/`](../ui/) and this folder keeps the old record.

| Folder | What it holds |
| --- | --- |
| [`design/`](design/) | The previous per-feature handoffs: Settings, the mobile shell, the table editor, Search, the Mermaid and Graphviz/WaveDrom editors, the AI composer and chat area, the 3D graph, the viewer scroll split, the edit-bar arrangement, and the preview/tab/focus fix. |
| [`architecture-design/`](architecture-design/) | Tab-bar sub-design notes: equalization, close animation, and the Mermaid designer UI handoff. |
| [`ui/`](ui/) | The earlier UI records that lived in `docs/ui/`: the shared edit window, the code-fence header, Sessions, the top-bar session picker, the workspace picker, and their mockups. |

These files still contain valid implementation facts about the shipped code. Read them as
source material when a redesign starts; do not follow them as the target. Relative links
inside this folder were rewritten when it moved, so they still resolve.
