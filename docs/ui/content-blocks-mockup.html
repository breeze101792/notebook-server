Reader — mixed notewide × auto

Bench log — 9 November

The DS18B20 rig ran for six hours on the 3V3 rail. The sensor is the only device on the bus, so the read path can skip the ROM search. The result is a signed 12-bit value in sixteenths of a degree.

Read path

Convert, wait 750 ms, then read the nine-byte scratchpad. The power gate stays on for the whole run.

static int ds18b20_read(int bus, int16_t *out_c)
{
    uint8_t scratch[9];

    if (ow_reset(bus) != 0)
        return -ENODEV;

    ow_write_byte(bus, 0xCC);      /* skip ROM */
    ow_write_byte(bus, 0x44);      /* convert T */
    k_sleep(K_MSEC(750));

    ow_reset(bus);
    ow_write_byte(bus, 0xCC);
    ow_write_byte(bus, 0xBE);      /* read scratchpad */
    for (int i = 0; i < 9; i++)
        scratch[i] = ow_read_byte(bus);

    *out_c = (int16_t)(scratch[0] | (scratch[1] << 8)) / 16;
    return 0;
}

4 · Figures and math

6 · `html-live` sandbox

A card with no padding, holding one sandboxed iframe. The frame starts at 260 px, fits its content height, and can be dragged taller. There is no header, label or error box.

Live HTML preview810 × auto

The frame is sandbox="allow-scripts" without allow-same-origin: cookies, storage, same-origin fetch, forms, popups, downloads, alerts and top-level navigation are blocked. The card is not a lightbox trigger. The copy-image button rasterises the stored source.
