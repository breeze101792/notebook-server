The edit window

The shared chrome of the table editor, the Mermaid designer and the DOT / WaveDrom designer. The current look is the target; the two additions in §10.4 are marked exception. The body is always a placeholder here: the table grid is table-editor.md, the designer sidebar / canvas / inspector are diagram-designers.md.

1 · The shell, empty

No badge, no window actions, no status. The three rows keep their heights and the history pair stays at the left. The body slot is the only per-window region. The modal is min(1320px, 96vw) × min(85vh, 92vh); this stage is 1376 px wide, so 96vw still exceeds the 1320 default.

  • Empty is legal. The badge collapses (:empty), the actions slot renders no placeholder, and the status is a zero-width live region.

  • History is pinned left, seam last in its group; the actions slot is the part that scrolls.

4 · Maximized

The transient .settings-modal--max class: the box fills the viewport, the radius goes to 0, the grip disappears, and both drag and resize are ignored. The glyph and label switch to Restore. Esc closes the window; it does not restore the box first.

8 · Error

A failed serialize or render leaves the window open, keeps the model, re-enables Apply and Cancel, writes the error status, and returns focus to the first inspector field or the canvas. The status colour is --warn today; §12 P4 proposes --danger.
