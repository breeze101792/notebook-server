Search view

Query row, Advanced disclosure, four filters, summary, and result list, at the default 240 px, the 140 px floor, and in the phone drawer. One-per-note is the shipped default. Every board uses the real result copy.

The mockup elides aria-controls wiring so cloned boards stay valid; the document is normative for ARIA. Focus is drawn with a class, not a live focus state: the field in the idle board, the active row in the results board, Retry in the error board, and the Advanced trigger at 140.
