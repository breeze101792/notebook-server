Tabs view

Static reference for tabs-view.md. The open files of the active session as a side-panel list. 240 default, 140 floor, 34 header, 30 rows, 24 actions; phone rows 44. Every row has the same four boxes: mark 14 (pin or module), label flex, state 14 (dirty or conflict), close 24 — the first, third and fourth reserved even when empty, so both edges hold.

1 · normal — both themes

2 · row anatomy — four boxes

mark 14label flexstate 14close 24

Identity leads, state trails. The pin or module icon sits in a reserved box before the name; the unsaved dot and the conflict glyph share one reserved box after it, because a conflict only exists on an unsaved file. Inserting either mark only where it applies is what made the names ragged; keeping the unsaved dot in front of the name is what made a clean row look different from a dirty one.

3 · states

Rest. transparent face
Hover. --surface-raised
Current. wash + 2 px marker
Dirty. state column, right of the name
Conflict. one state column, glyph instead of dot
Pinned. pin leads; the close column is an inert gap
Special. module sprite + italic label
Focus. inset ring
Dragging. --opacity-drag
Drop before. 2 px line
Drop after. 2 px line

Hover is neutral; only the current row is tinted. Weight is 400 everywhere. The state box is always present, so the name's truncation point does not move when a file becomes dirty. The last three rows are the drag marks of §4.5: the dragged row dims, the target takes a 2 px accent edge on the half the pointer is in.
