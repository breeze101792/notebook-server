Heading level legibility — options board

Five columns over one identical sample note: h1, h2, h3, two h4s, h5, h6 and paragraphs. V1–V4 are the options as first written; V6 is the chosen design — V4's ramp plus V1's gutter label. The ramp is the shipped one — 1.9 / 1.5 / 1.25 em at weight 650, line 1.25, h4–h6 at 1em — except in V4 and V6, which carry the ramp change. The boards are narrower than the real 772 px column, so lines run short; the type is at shipped size. Scroll the board sideways to reach every column.

A static page cannot hover and has no caret. Each label column draws its h3 with the label visible, standing in for a live reveal. In V6 the h3 stands for the caret inside the heading and the second h4 for pointer-over; its caption says which. Hovering any other heading in a browser shows the live state.

V6 is the choice. V6 = V4's ramp + V1's label, hybrid only, by caret or pointer. V4 alone is superseded: its ramp is half of V6. V1–V3 are not chosen.
Not chosen

V1 — gutter hover badge

An H2 label in the left gutter, visible only under the pointer. Nothing at rest.

Sensor node bring-up

The node wakes on a 10 s timer, samples the shunt and writes one record to flash. Sleep current is 12 µA.

Power path

The LDO holds 3.3 V while the cell stays above 2.9 V. Below that the boost converter takes over.

Brown-out reset

BOR is set to 2.7 V. One reading below it latches the reset flag until the counter clears.

Threshold trim

Trim is written at test and must not be rewritten in the field.

Recovery

After a reset the node reports the cause in the first packet.

Log format

Sixteen bytes per sample, little endian.

Revision note

Rev C moves the shunt to the low side.

The h3 is drawn with its label visible — the hover state. Every other heading shows the rest state: nothing. Hybrid mode hides the label, so it does not help while writing.

H3 — caret inside (hybrid). Always shown while you type in it.

H4 “Recovery” — pointer over (hybrid). Same label before the click, so the level is readable on the way in.

At rest on every other heading. The ramp alone carries the level.

The label is 9 px --text-2xs, muted, never part of the text — a pseudo-element, so it cannot be selected, deleted, saved or undone — and absent on phone, in print, and inside lists, quotes and tables.
