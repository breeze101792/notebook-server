App

Rail slots, budget 7: 1 Explorer · 2 Sessions · 3 Bookmarks · 4 Recent files · 5 Search · 6 spare view slot (reserved, empty today) · 7 More, pinned last. Five views are assigned, so six buttons render at 62 px each in a 390 board; the 44 px floor binds at 320. Glyph 17 px; 56 + bottom inset.

Sheet row model: grabber 36 × 4 · header 52 with a 44 px × · group label 12 / 600, .08em, uppercase · row 52, gap 12, padding 0 16, icon box 24 wide holding a 17 px sprite, label 15 / 1.3 · 1 px border between rows, none after a group's last · press face accent-soft · danger row danger · cap min(72dvh, 560px), radius 16 top, scrim .45. The scrim (z 400) and the sheet (z 600) paint over the rail (z 150), so More shows no open face: only aria-expanded changes. Under the default order the Views group is empty and is not rendered.

Static boards. Drawer, sheet and history behaviour is described in mobile-shell.md; the shell query lives in style.css.
