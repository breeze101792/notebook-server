Outline — tree-style guide lines

The outline's sub-headings get the file tree's guide cells: each level below an H1 costs one 12 px column, ending in the row's own ├── / └── corner. An H2 starts at column 0, so the indent is one step per level and nothing more. An H1 is a flat section title and spends no column. The cells and their 1 px --border strokes are the tree's own .tree-guide markup. Spec: docs/ui/shell-frame.md §5.3.

C. The tinted boxes are the 12 px cells (mockup-only shading). The active row's guide is two cells: its H2 parent's pipe and its own └ corner.

  • Cell — 12 × row height, one per level below an H1, flex-shrink: 0.
  • Pipe — left: 5px, 1 px, --border, drawn top/bottom: -3px so adjacent rows meet in one unbroken stroke.
  • Corner — a 7 px horizontal stub from the pipe to the label; cnr-last stops the stem at the junction (└), cnr continues it (├).
  • Empty cell — a depth whose branch already ended; keeps the width, draws nothing.
  • Section title — an H1: empty guide, no corner, flush left. Its children start at column 0, like the first level of tree output.
  • Anchor — flex: 1 1 auto; min-width: 0, so long headings still ellipsize; its 2 px accent bar starts after the guide.

outline.js builds the tree by heading level and emits one guide per row; an H1's children start at column 0, so depth costs one cell per level. style.css adds the flex box, the anchor's flex: 1 1 auto; min-width: 0, and narrows the file tree's cells to --outline-indent 12 px.
