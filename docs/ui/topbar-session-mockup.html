Top bar — the active session name

The current session is named beside the workspace chip: Notebook │ Notes │ Deep work. It is a label, not a control — no face, no border, no hover, no new tab stop. It is filled by the client from the session model, so it survives a rename, a switch and a delete without a reload.

The label is the workspace chip's type size with one step less emphasis: .84rem at weight 500 in --fg-muted, no face. The glyph is 12 px, the same box as the chip's. The whole label is inside the 46 px row, so the bar keeps its height.

4 · A long name

Session names cap at 40 characters. The label ellipsises at 17em and carries the full string in its title, prefixed so a hover explains the element as well as the name. The tooltip below is drawn — a real title cannot be screenshotted.

Why 17em and not no cap: an uncapped label would push against the spacer, and in a short window would take room the workspace name needs. The name is never truncated in the model — only in this one line, with the full string one hover away.

5 · A narrow desktop window

The topbar at 861 px — the narrowest width that is still the desktop shell. A long brand, a long workspace name and a long session name share the shortfall: all three ellipsise, and nothing overflows. The actions keep their width because a flex item never shrinks below its content.

8 · The alternatives, and why not

Each of these was drawn and rejected. The reasons are the design, not a matter of taste: each one adds a second job to an element that already has one.

A · a chip that opens Sessions

B · merged into the workspace chip

C · in the tab bar

Deep work
Sensors.md
DirectionVerdict
A · a chip that opens SessionsRejected. It adds a second control that switches the side panel, duplicating the 🗂 rail icon, plus a tab stop, a hover face and a focus ring — for a request to show a name. Hover would also promise a menu, because that is what the chip beside it does.
B · merged into the workspace chipRejected. The chip is the workspace picker: its menu lists workspaces, not sessions. Clicking a label that names a session to open a workspace list is a lie. It also makes a 40-character session name compete with the workspace name inside one 240 px box.
C · in the tab barRejected. The strip is the session's content; session chrome there competes with the tabs at exactly the widths where tabs need the room.
D · right-aligned by the actionsRejected. Placed at the right edge it reads as a status readout and moves whenever an action appears or disappears. The left cluster is the identity of what you are looking at.

ARIA: the wrapper and the label are plain span elements with no role, no aria-label and no tab stop. The value is read as text. The glyph is aria-hidden. The divider is aria-hidden. There is nothing to announce and nothing to focus.
