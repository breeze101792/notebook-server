Settings modal — seven tabs

The shipped Settings surface, codified. Dark and light boards use the foundation tokens only. Every size, colour and space is the shipped value. Proposals live in settings-modal.md §12 and are not drawn here.

File watching

Get notified when files in your notebook are changed by another program (vim, a sync tool, a different browser tab, etc.). Detection runs by default using a 5-second poll. Click Enable below to upgrade to the native folder observer, which is push-based and uses no network -- the browser will ask for permission to read your notebook folder.

Keyboard

Enable VIM-style keybindings. When on, the sidebar, outline, and editor act as three vim "windows" (Ctrl+W to cycle). Inside the editor itself, CodeMirror 6's vim mode gives you full VIM (normal/insert, motions, text objects, :w to save, :q to exit, etc.). Press ? from the shell for the full keymap.

  • Focus. The ring is 2px solid --accent at a 1 px offset; the switch uses 2 px. Fields replace the ring with an accent border and a 3 px wash.
  • Nav glyphs. The shipped surface uses emoji — gear, books, palette, keyboard, lock, sparkle, info. This machine has no emoji font, so every board draws the same seven marks on the 16 grid at 14 px in currentColor — same 1.4em column, same colour, same size. The source remains the emoji; sprite replacement is proposal P1. The same applies to the lock in Read-only and the sparkle in the AI help sentence.
  • Density. The 30 px field and the 1.27:1 border are shipped values, not targets. Proposals P3 and P4 cover them.
