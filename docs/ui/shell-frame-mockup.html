The shell frame

Topbar, activity rail, the two panel frames and the phone conversion. The six shell states at real size, a rail detail, the control states, then the light pair. Every value is a token from foundations.md or one of the five additions in §9.1.

1 · The grid

Four columns. Only the two panes resize. The reader keeps a 352 px floor, so the panes share a budget: 60 % of it to the side panel, 40 % to the outline, neither below 140.

4 · Control states

Hover, active and focus are shown side by side as stills. The ring is the shared 2 px --accent; inside a clipped list or an 8 px strip it is inset.

5 · Light theme

Same geometry, same tokens. Only colour and shadow alpha change. The chips' border is --border-strong, which measures 3.36:1 on --surface-raised; the hairline --border at 1.27:1 would fail the control floor.
