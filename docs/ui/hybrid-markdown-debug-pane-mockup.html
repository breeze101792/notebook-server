Markdown debug pane — hybrid mode

Six boards. The left column is the hybrid page and never changes. The right column is the read-only Markdown the next Save would write — domToMarkdown() of the live DOM, not the frozen file on disk. The two columns scroll together, proportionally. The toggle is a 26 px edit-bar control using the new #nb-icon-split symbol.

Tokens are the app's foundation tokens; no new token is introduced. The pane is a sibling of #viewer inside #edit-split, so the serializer never sees it.
