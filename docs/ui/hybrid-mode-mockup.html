Ten boards, each authored once and repeated in the light theme. Every value is a foundation token or the shipped CSS value cited in docs/ui/hybrid-mode.md. The note is content; the chrome is the design. Annotation text outside a board is not product chrome.

Glyphs: chrome glyphs are drawn as plain SVG or a non-emoji character where this machine has no emoji font; two emoji-only edit-bar buttons are omitted. The shipped markup still uses emoji at index.html:178, :181 and hybrid.js:46 until foundations §9.3 replaces them.

Deliberate deltas from today's stylesheet: the active toggle's label is --text-on-accent instead of white (E1, 2.61:1 → 6.99:1 in dark), and the Save hover takes the same label (E1b). Flash bring-up

The first keystroke reveals Save and adds the dot to Close. Autosave will write the bytes silently after the quiet period; Mod+S writes now and toasts “Saved”.

If the write fails, the browser alert is the surface and the editor stays open.

tab dot: 8 px accent Close: accent border + 9 px dot Save: floppy glyph in accent; hover is a fill

Dirty is never colour alone: a dot on Close and the tab, plus the Save glyph. On the phone the tab strip is gone, so the Save glyph and the Done dot carry it.
